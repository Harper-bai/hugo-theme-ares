ブログには、気づいたこと、理解できたこと、まだ考えていることが残ります。Ares は、その言葉のためにページを整えるテーマです。明確な見出し、読みやすい本文、余白、次の記事への入口を用意しています。

<!--more-->

## 見慣れたページを Hugo で

Ares は Hexo のテーマとして生まれました。このバージョンは [Hugo](https://gohugo.io/) で動きます。元のレイアウト、ローカルフォント、アイコン、ライト・ダークの配色、スマートフォンでの読み方を引き継いでいます。

記事は Markdown で書き、Hugo で静的なページを生成します。まずローカルで表示とリンクを確認し、生成したファイルを静的サイトのホスティングサービスに公開できます。公開後のサイトで Hugo を常時起動する必要はありません。

## 新しい記事から過去の記事へ

ホームには日付順に記事が並びます。要約の区切りを入れると、導入と続きを読むリンクを表示します。区切りを入れない短い記事は、ホームで全文を読めます。

記事が増えたら、次の入口を使って探せます。

| ページ | 役割 |
| --- | --- |
| [アーカイブ]({{< relref "/archives" >}}) | 年ごとに記事を振り返る |
| [カテゴリー]({{< relref "/categories" >}}) | ブログの継続的な分野を読む |
| [タグ]({{< relref "/tags" >}}) | 同じ道具や話題の記事を探す |
| [このサイトについて]({{< relref "/about" >}}) | 著者とブログの目的を知る |
| [リンク]({{< relref "/friends" >}}) | おすすめのサイトを訪れる |

キーワードを覚えていれば、ナビゲーションの検索を使えます。検索用のデータはサイトと一緒に生成され、標準では現在の言語の記事だけを検索します。

## 読む習慣をそのままに

配色はシステム設定に合わせて切り替わり、手動でも選べます。選んだ配色はブラウザーに保存されます。スマートフォンではナビゲーションをメニューにまとめ、本文は一列で表示します。

コードにはファイル名、行番号、強調する行を指定できます。コピーや長いコードの展開にも対応しています。記事の末尾から前後の記事へ進み、ページ上部へ戻るボタンも使えます。

画面の文言は中国語、英語、日本語を用意しています。翻訳がある記事では言語メニューから対応する記事へ移動し、翻訳がなければ選んだ言語のホームへ移動します。この紹介記事も三つの言語で読めます。

## まずは一つの記事から

ブログ名、著者名、ドメインを設定したら、書きたい記事を一つ公開してみてください。コメント、数式、アクセス解析は必要になったときに追加できます。サンプルサイトでは外部サービスを無効にし、基本の表示にはリポジトリー内のフォント、スタイル、スクリプトを使っています。

<details>
<summary>使い始めるために必要なものは？</summary>

Hugo 0.158.0 以降をインストールしてください。通常版で動作します。プレビューとサイト生成には、Hexo、Node.js、npm の依存パッケージは不要です。

Sass のソースを変更して CSS を再生成するときだけ、任意の npm 開発用パッケージを使います。

</details>

インストール手順は[リポジトリーの README](https://github.com/Harper-bai/hugo-theme-ares)にあります。中国語のサンプル記事には、サイトの作成、記事の書き方、アーカイブとタグの整理についても説明があります。
