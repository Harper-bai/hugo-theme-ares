一个博客最值得留下的，是作者看过什么、想通什么、还在追问什么。Ares 把页面留给这些内容：清楚的标题、舒适的正文、安静的留白，以及随时能找到的下一篇文章。

<!--more-->

## 熟悉的页面，新的起点

Ares 原本是 Hexo 主题，这个版本让它运行在 [Hugo](https://gohugo.io/) 上。原有的页面布局、离线字体、图标、明暗配色与手机阅读方式继续保留。文章写在 Markdown 文件里，Hugo 将它们生成静态页面。

你可以先在本地预览，确认内容与链接，再把生成的文件部署到静态托管服务。发布后的页面不需要服务器运行 Hugo。

## 从首页读到旧文章

首页按时间展示文章。有摘要分隔符的文章会显示摘要和阅读全文入口；短文不设置分隔符时，可以直接在首页读完。

当文章逐渐增多，时间、主题与背景信息各有自己的入口：

| 页面 | 用途 |
| --- | --- |
| [归档]({{< relref "/archives" >}}) | 按年份回看文章，沿时间寻找线索 |
| [分类]({{< relref "/categories" >}}) | 浏览技术、读书、随笔等长期栏目 |
| [标签]({{< relref "/tags" >}}) | 聚合同一个工具、问题或话题 |
| [关于]({{< relref "/about" >}}) | 介绍作者与博客的写作方向 |
| [友链]({{< relref "/friends" >}}) | 推荐你愿意再次访问的网站 |

知道关键词时，还可以打开导航中的搜索。搜索索引随站点一起生成，默认只包含当前语言的文章。

## 让阅读习惯自然延续

明暗主题会跟随系统设置，也可以手动切换。浏览器会记住手动选择，下一次打开时继续使用。手机上的导航收进菜单，正文仍保持单列阅读。

技术文章可以显示代码文件名、行号与指定行高亮。读者能复制代码，也能展开较长的代码块。读到文章末尾，可以通过相邻文章继续浏览，或使用返回顶部按钮回到开头。

主题还提供中文、英文和日文界面。同一篇文章有译文时，语言菜单会进入对应译文；没有译文时，进入所选语言的首页。这里的介绍文章也提供了英文和日文版本，可以直接体验。

## 先写，再按需要配置

第一次使用时，先完成博客标题、作者和域名配置，再发布一篇真正想写的文章。评论、数学公式和访问统计都可以稍后启用。示例站默认关闭这些外部服务，基础阅读使用仓库内的字体、样式和脚本。

<details>
<summary>开始之前：需要安装哪些工具？</summary>

安装 Hugo 0.158.0 或更新版本，普通版即可。预览和生成站点不需要 Hexo、Node.js 或 npm 依赖。

只有修改 Sass 样式源码时，才需要安装可选的 npm 开发依赖，并重新生成仓库中的 CSS 文件。

</details>
